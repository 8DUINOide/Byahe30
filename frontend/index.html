04 HOW BYAHE30 WORKS

Useful signals.
Honest estimates.

Scheduled waves estimate where a typical run might be from service frequency, road-following OpenStreetMap geometry, and traffic-adjusted segment times. In-transit GPS and Para Alert run only in the commuter’s browser and are never sent to the server.

During overnight hours, the app uses historical or seeded baseline values and makes no live traffic or weather requests. Optional TomTom traffic and incident data is polled server-side on quota-aware Manila-time intervals; Open-Meteo rain alerts adjust estimates. The corridor’s stop coordinates and baseline times remain planning estimates pending local validation.
