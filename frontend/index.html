04 HOW BYAHE30 WORKS

Useful signals.
Honest estimates.

Scheduled waves estimate where a typical run might be from service frequency and road times. A live phone report appears only when a participating driver shares location; it expires when updates stop.

During overnight hours, the app uses historical or seeded baseline values and makes no live traffic requests. The current starter corridor uses approximate place coordinates and baseline times pending local validation. Bus arrival times from a live phone report are estimates, not guarantees.
